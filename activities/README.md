# Generative AI for Project Management — Activities

**Course Code:** C013  |  **Conducted by:** Tertiary Infotech Academy Pte Ltd (UEN 201200696W)  |  **Version v1.0 · 19 September 2026**

25 hands-on activities. Every activity is GenAI-first: you prompt a Generative AI tool for a first-pass artifact, then critically review, correct and complete it.

Each activity has its own folder containing the Markdown guide and matching PDF, a prompt sheet, a detailed instruction manual and a formatted mock-data workbook. Start with the linked guide.

## GenAI tools used

- **ChatGPT** — chat.openai.com — general drafting, tables, analysis.
- **Claude** — claude.ai — long documents, structured reasoning, critique.
- **Gemini** — gemini.google.com — research-backed drafting and Workspace integration.
- **Microsoft Copilot** — copilot.microsoft.com — drafting inside Office documents.
- **Project Manager Buddy GPT** — A purpose-built PM GPT used throughout this course.

Project Manager Buddy GPT: https://chatgpt.com/g/g-hUcEmp6Rp-project-manager-buddy-project-management
