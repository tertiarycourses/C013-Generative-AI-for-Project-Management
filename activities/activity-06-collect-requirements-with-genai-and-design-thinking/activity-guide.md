# Activity 6 — Collect Requirements with GenAI and Design Thinking

**Course:** Generative AI for Project Management (C013)  
**Topic 01:** Project Initiation and Planning with GenAI  
**Learning outcome:** LO1 — Elicit, structure and prioritise requirements using GenAI-supported techniques.  
**Tools:** Design Thinking Studio (alfredang.github.io/designthinking) · GenAI tool · MoSCoW with Sliders Template.xlsx

## Goal

Requirements gathering is where GenAI earns its keep. You will run brainstorming, affinity clustering and prioritisation — using the Design Thinking Studio to structure the work and dot-vote as a group.

## What you'll produce

A clustered, prioritised requirements set with a MoSCoW classification.

## Core prompt

```text
Create three user personas and their top pain points for [your project's users]. Then list 15 to 20 ideas for solving the highest-priority pain point. Mark assumptions that require user research.
```

## Step-by-step

1. One member opens https://alfredang.github.io/designthinking/ and clicks 'Create New Workspace'. Everyone joins with the workspace code or QR, entering their display name.
2. Go to stage 1, Empathize. Prompt GenAI: 'Create 3 user personas and their top pain points for [your project's users].' Add each persona as a note in the User Personas section and each pain point under User Pain Points.
3. Fill the Empathy Map quadrants — Says, Thinks, Does, Feels — for your primary persona, using GenAI to draft and your own judgement to correct.
4. Move to stage 2, Define. Prompt: 'Write a clear problem statement and five How Might We questions for [the pain points above].' Add these to the Problem Statement and How Might We Questions sections.
5. Move to stage 3, Ideate. Prompt: 'Provide a list of brainstorming prompts or questions related to [topic or problem] to stimulate creative thinking and generate a diverse range of ideas', then 'List 15-20 ideas for [your problem].'
6. Add the ideas to the Brainstorming Board. Then cluster them: group similar ideas and label each cluster with a clear theme — this is your affinity analysis.
7. Use the Voting & Prioritisation section, which has voting enabled. Each learner votes on the ideas they believe should be built. Read off the top five by vote count.
8. Open 'MoSCoW with Sliders Template.xlsx'. Prompt GenAI: 'Classify these requirements as Must have, Should have, Could have or Won't have for a first release, and justify each classification.'
9. Override any classification your group disagrees with — GenAI systematically over-classifies things as 'Must have'. Share your prioritised set with the class.

## Check your work

✅ Your workspace has personas, an empathy map, a problem statement, a clustered idea board with vote counts, and a MoSCoW list where you changed at least one AI classification.
