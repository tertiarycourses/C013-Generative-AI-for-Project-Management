# Activity 5 — Assign Responsibilities with the RACI Ed-Tool

**Course:** Generative AI for Project Management (C013)  
**Topic 01:** Project Initiation and Planning with GenAI  
**Learning outcome:** LO1 — Allocate project responsibilities unambiguously using a responsibility assignment matrix.  
**Tools:** RACI Collaborative Matrix (alfredang.github.io/raci) · GenAI tool

## Goal

A RACI matrix ends the 'I thought you were doing it' conversation. You will build one collaboratively in a live browser tool, using GenAI to propose the first pass.

## What you'll produce

A completed RACI matrix for your project, agreed by the whole group.

## Core prompt

```text
For a project with these activities [paste] and these roles [paste], propose a RACI assignment. Give exactly one Accountable role per activity and explain any ambiguous accountability.
```

## Step-by-step

1. One member of your group opens https://alfredang.github.io/raci/ and clicks 'Create new board'. Share the QR code or board URL from the 'Share' button so everyone joins.
2. Note the board arrives pre-seeded with a GenAI project example — roles Solution Architect, Platform Team, Security & Compliance, Data/Knowledge Owner and five activities. Rename these to match your own project by clicking each header.
3. Use '+ Add role' and '+ Add activity' to complete your grid. Aim for 4–6 roles and 6–8 activities.
4. Prompt GenAI: 'For a project with these activities [paste] and these roles [paste], propose a RACI assignment. Give exactly one Accountable per activity and explain any activity where accountability is ambiguous.'
5. Drag the A, R and C markers into the cells to match the AI's proposal. Note this tool uses A/R/C only — there is no Informed marker, so record 'informed' parties in your communications plan instead.
6. Now audit it as a group. Check the two rules that matter: exactly ONE Accountable per activity, and no role that is Accountable for everything. Click a marker to remove it, or drag it to the trash.
7. Find at least one place where the AI's suggestion was wrong for your organisation and fix it. Ask why it got it wrong — usually it assumes a generic org structure.
8. Screenshot the finished board (the tool has no export) and share it with the class.

## Check your work

✅ Every activity row has exactly one A, at least one R, and your group can justify each assignment; you have a screenshot saved as evidence.

**Remember:** GenAI gives you a fast first draft. Check every figure, source and assumption before the output leaves your hands — you remain accountable for it.
