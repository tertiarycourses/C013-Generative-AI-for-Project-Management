## About the course

This course covers project initiation, planning, execution, delivery, risk management and closure. Learners use GenAI to create a first draft of each project artifact, then check the model's assumptions, arithmetic, sources and recommendations before completing the deliverable.

## Learning outcomes

- LO1: Develop project parameters with GenAI according to business requirements.
- LO2: Resolve project delivery challenges by optimising resource and project budgets with GenAI.
- LO3: Anticipate and devise risk mitigation measures with GenAI to ensure project success.

## Topics covered

1. Project Initiation and Planning with GenAI - charter, business case, stakeholders, requirements, scope, WBS, schedule and cost.
2. Project Execution and Delivery with GenAI - work performance, knowledge, quality, resources, team and communications.
3. Managing Project Risks with GenAI - risk analysis and responses, procurement, change control, earned value, quality control and closure.
