## About

This repository contains the complete lab and courseware package for **Generative AI for Project Management** (**C013**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Build the AI Working Agreement and Project Charter** to **Close the Project and Capture Reusable Lessons**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **9 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **Approved AI assistant · Spreadsheet · Text editor** and the supporting resources supplied in the repository.
- Begin with **Build the AI Working Agreement and Project Charter** and finish with **Close the Project and Capture Reusable Lessons**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **Approved AI assistant · Spreadsheet · Text editor**. Follow the setup and access notes in each lab.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C013---Generative-AI-for-Project-Management.git
cd C013---Generative-AI-for-Project-Management
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–9 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
